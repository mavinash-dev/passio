# 50 Brands Execution Checklist

## Weekly Plan (Repeat x10)

- [ ] Research and shortlist 5 new creator brands
- [ ] Prepare outreach messages (see OUTREACH_TEMPLATE.md)
- [ ] Send DMs/emails to selected creators
- [ ] Collect info, images, and stories from each creator
- [ ] Create profile using PROFILE_TEMPLATE.md
- [ ] Publish profile on Passio platform
- [ ] Feature brand on Instagram (organic + paid boost)
- [ ] Track engagement, DMs, and inbound requests
- [ ] Log all progress and learnings

## Ongoing
- [ ] Prioritize inbound requests for early features
- [ ] Maintain quality and consistency in profiles
- [ ] Review and refine outreach and profile templates as needed
- [ ] Monitor Instagram analytics and adjust promotion budget
- [ ] Prepare for self-serve onboarding after 50 brands
